options:

  --project PATH        runs of the repo at PATH (default: the repo of the
                        current directory, with its worktrees)
  --all                 every repo: one block per repo, then the total
  --since YYYY-MM-DD    runs invoked on or after this local date
  --until YYYY-MM-DD    runs invoked on or before this local date
  --session ID          one run's own figures instead of medians (any repo)
  --compare-since YYYY-MM-DD
                        medians before this date next to those since it, with
                        the difference
  --weights FILE        JSON file overriding weights, optionally with prices
  --strict              exit 1 when any run in the selection was left out
