# Tasks: Run each phase boundary of /feat and /fix with one command

**Input**: Design documents in `specs/013-step-command/` (spec.md, plan.md, research.md, data-model.md, quickstart.md, contracts/step-cli.md, contracts/gates.md, contracts/agent-formats.md, contracts/sizes.md, contracts/coordinator.md)

**Prerequisites**: plan.md, spec.md

**Tests**: Requested (FR-028, SC-002, SC-003, SC-004): offline tests in `tests/step/run.sh` (fixtures, goldens, throwaway repos, `log-readers-agree`), tagged fixtures in `tests/state/`, `sizes.tsv` cases in `tests/sizes/`. `tests/state/` and `tests/sizes/` are the pattern.

**Organization**: Setup, Foundational (sizes data, `state.sh` tags, the `step.sh` skeleton, the test harness), US1 (P1, one call per boundary), US2 (P1, report formats and digests), US3 (P2, merged review findings), US4 (P2, base, repair and diff checks; `move.md`), US5 (P2, gate tags and answers), US6 (P3, the skills and the harness keep the coordinator's part), Polish (docs, full checks, scratch runs). The plan's How steps 1–18 map onto them.

## Format: `[ID] [P?] [Story] Description`

- **[P]**: can run in parallel (different files, no dependency on an incomplete task)
- All paths are relative to the repository root. `step.sh` is `.apm/skills/feat/scripts/step.sh`, `state.sh` is `.apm/skills/feat/scripts/state.sh`. `step.sh` is one file, and every case is declared in `tests/step/run.sh`: tasks touching either are sequential, never [P]. Fixture files are separate files and may be [P].
- `step.sh`: bash 3.2 constructs only (no `declare -A`, `mapfile`/`readarray`, `${v,,}`/`${v^^}`, `declare -n`/`local -n`, `[[ -v`, `;;&`, `|&`; empty arrays as `${a[@]+"${a[@]}"}`), `LC_ALL=C`, `set -euo pipefail`, `set -f`, `shellcheck`-clean, no `jq`, no Python at run time; it changes the state file only through `bash state.sh set|log`.
- Never hand-edit between `sizes-start`/`sizes-end` markers, CHANGELOG.md, versions or `.release-please-manifest.json`. `harness.md`, `rebase.md` and `move.md` carry no `/feat`-only words (`specifier`, `planner`, `tasker`, `spec.md`, `brief`, `phase <n>`, `/feat`).
- D13 (spawn list inputs in a file) is out of this feature (#69): no task for it.
